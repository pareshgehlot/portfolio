# Paresh Gehlot — Portfolio

A single-page portfolio website highlighting Paresh Gehlot’s leadership, engineering experience, and award-winning projects.

## Local development

Open `index.html` in any modern browser. The page is entirely static and does not require a build step.

## Deploying to GitHub Pages

1. Commit the contents of this repository to a GitHub repository.
2. Push to a branch named `main` or `master`.
3. In the GitHub UI, navigate to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. GitHub Pages will publish the site at `https://<your-username>.github.io/<repo-name>/` after a short build.

## Customization tips

- Update the content in `index.html` to add new achievements or projects.
- Adjust colors, typography, and layout tokens in `styles.css`.
- Enhance interactivity by extending the lightweight filter logic in `script.js`.
